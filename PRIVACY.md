# Privacy and offline operation

The plugin locally reads selected runtime messages, object/parameter identities, verified wire connections and bounded data/reference samples inside Rhino. It does not transmit definitions, geometry or diagnostics and contains no AI API or telemetry client.

Locate changes selection/view. The assistant does not edit values, persistent data, geometry or wires, load references, solve or save definitions. You make repairs and recompute yourself.

Copy error report writes to the local clipboard. It can include object names, IDs, runtime text and details of the inspected definition. Review and redact before sharing. Rhino licensing, GitHub downloads, Yak and unrelated plugins have their own network behavior; the offline claim applies to this diagnostic plugin.
