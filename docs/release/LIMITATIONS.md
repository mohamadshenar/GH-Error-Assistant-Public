# Supported scope and limitations

- Windows / Rhino 9/default .NET 10 / Grasshopper 1. Native evidence is bounded to Rhino 9.0.26300.9401 / GH 1.0.0009 / .NET 10.0.12. Future hosts/alternate runtimes require appropriate verification.
- No qualified Rhino 8, GH2, macOS or Rhino.Inside support.
- 150%/200% DPI and complete dark appearance are unverified. Earlier 125% default-state evidence is not complete minimum/advanced coverage. Stable UI inspection used 96 DPI/light appearance.
- No pristine clean-profile installation or complete exception-log coverage. Existing-profile direct upgrade and fresh startup are not universal crash/leak guarantees.
- Supported fingerprints showed no unexpected changes; generic slider PersistentData was unsupported and supplemented by independent getters. Not every third-party property/geometry type was measured.
- Inspection is bounded. Clusters, deleted/unavailable objects, large trees and third-party getters may limit findings. Candidate investigation order is not causal ranking.
- Reference existence does not prove suitability. Warning disappearance does not verify intended output. Repair, recomputation and saving remain manual.
- Locate intentionally changes selection/view. Identity safeguards may refuse navigation; Back can retain explicitly historical findings.
